## 🎯 How to Use

### Basic Code Editing
1. **Create New File**: Click "New" button or press `Ctrl+N`
2. **Open File**: Click "Open" button or press `Ctrl+O`
3. **Save File**: Click "Save" button or press `Ctrl+S`
4. **Switch Files**: Click on tabs or use the file explorer

### AI Assistance
1. **Inline Help**: Press `Ctrl+K` for AI suggestions at cursor position
2. **Chat with AI**: Use the right panel to ask questions about your code
3. **Code Completion**: Click "Complete Code" in AI shortcuts
4. **Explain Code**: Select code and click "Explain Code"
5. **Refactor**: Select code and click "Refactor" for improvements
6. **Generate Tests**: Click "Generate Tests" to create unit tests

### Terminal Commands
1. **Regular Commands**: Type normal terminal commands (ls, cat, npm install, etc.)
2. **Natural Language**: Type commands in English ("install react dependencies")
3. **AI Conversion**: The AI will convert natural language to actual commands

### Project Creation
1. Click the "+" button in the file explorer
2. Choose from available templates:
   - **React App**: Modern React application with TypeScript
   - **Node.js API**: Express.js REST API server
   - **Python App**: Flask/FastAPI application
   - **Android App**: Kotlin Android application
   - **Desktop App**: Electron/Tauri desktop application
   - **Game**: JavaScript/TypeScript game

### Building Projects
1. Click the "Build" button in the top menu
2. The AI will detect your project type automatically
3. Watch the build process in the output panel
4. Get executable files, APKs, or deployable builds
