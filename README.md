# CrazyIDE - The Ultimate Development Environment 🚀

A feature-rich, web-based IDE built with modern technologies and a crazy attention to detail!

## Features

### ✨ Core IDE Features
- **Monaco Editor Integration** - Professional code editor with syntax highlighting
- **Multi-language Support** - JavaScript, TypeScript, Python, HTML, CSS, and more
- **File Explorer** - Complete file tree navigation and management
- **Multiple Tabs** - Work with multiple files simultaneously
- **Search & Replace** - Powerful search functionality across files
- **Command Palette** - Quick access to all IDE commands (Ctrl+Shift+P)

### 🎨 Theming System
- **Multiple Built-in Themes** - Dark, Light, Monokai, Dracula, Solarized
- **Custom Theme Creator** - Build your own themes with live preview
- **Responsive Design** - Looks great on all screen sizes

### 🔧 Advanced Features
- **Integrated Terminal** - Full web-based terminal emulator with command history
- **Git Integration** - Complete version control with staging, commits, push/pull
- **AI Assistant** - Smart coding assistant with chat interface
- **Extension System** - Plugin architecture with built-in extensions
- **Live Preview** - Real-time preview for web development
- **Code Formatting** - Prettier integration for code formatting

### 🤖 AI Assistant
- **Smart Code Completion** - AI-powered suggestions and snippets
- **Interactive Chat** - Ask questions about your code
- **Debugging Help** - Get assistance with errors and bugs
- **Best Practices** - Learn coding standards and optimization tips
- **Multi-language Support** - Help with JavaScript, Python, HTML, CSS, and more

### 📁 File Management
- **Create/Delete Files** - Full file and folder management
- **File Upload/Download** - Drag and drop file support
- **File Search** - Find files by name or content
- **Recent Files** - Quick access to recently opened files

### 🔄 Git Integration
- **Visual Git Status** - See modified, staged, and untracked files
- **Branch Management** - Create, switch, merge, and delete branches
- **Commit History** - View commit timeline and changes
- **Remote Operations** - Push, pull, and fetch from remote repositories
- **Diff Viewer** - Compare file changes

### 🛠 Extensions
- **Prettier Code Formatter** - Automatic code formatting
- **ESLint Integration** - JavaScript/TypeScript linting
- **Emmet Support** - Fast HTML/CSS development
- **Color Picker** - Advanced color selection tools
- **Live Preview** - Real-time HTML preview

### ⌨️ Keyboard Shortcuts
- `Ctrl+N` - New File
- `Ctrl+O` - Open File
- `Ctrl+S` - Save File
- `Ctrl+Shift+P` - Command Palette
- `Ctrl+F` - Find in File
- `Ctrl+H` - Find and Replace
- `F5` - Run File
- `Ctrl+`` - Toggle Terminal
- And many more!

## Getting Started

1. **Open the IDE**: Simply open `index.html` in your web browser
2. **Create a New File**: Click "New File" or use Ctrl+N
3. **Start Coding**: Use the Monaco editor with full syntax highlighting
4. **Chat with AI**: Switch to the AI Assistant tab for coding help
5. **Manage Files**: Use the file explorer to organize your project
6. **Use Terminal**: Access the integrated terminal for command-line operations
